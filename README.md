# Frank Launcher

A minimal Android launcher with a plain design.

## Features
- **Widget grid** (top half, configurable height)
- **Favorite apps** as text-only list (bottom)
- **Swipe left** to open full app drawer with auto-focused search
- **Long press** on empty space for bottom sheet menu (settings, lock/unlock)
- **Theme support** — Light, Dark, or follow system

## Building

```bash
./gradlew assembleDebug
```

## Requirements
- Android 10+ (API 29)
- Kotlin 2.0 / Jetpack Compose
